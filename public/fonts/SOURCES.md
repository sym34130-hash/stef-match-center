# League fonts

Unmodified font binaries from the Google Fonts repository (retrieved 2026-11-02):

- Archivo Black, normal 400: https://github.com/google/fonts/tree/main/ofl/archivoblack
- Barlow Condensed, italic 900: https://github.com/google/fonts/tree/main/ofl/barlowcondensed

Both are distributed under SIL Open Font License 1.1. The original copyright
and license notices are included alongside each font. These are the same two
variants previously requested from Google Fonts. Archivo Black is the primary
league display face; Barlow Condensed remains the existing fallback.
